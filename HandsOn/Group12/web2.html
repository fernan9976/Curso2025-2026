                        💡 ¿Por qué RDF y Linked Data?
                    

                    

                        

                            
🔗

                            
Interoperabilidad

                            
Los datos se enlazan con Wikidata, permitiendo integración con otros datasets globales

                        

                        

                            
🧠

                            
Semántica Clara

                            
Las relaciones tienen significado explícito (gz:inDistrict conecta zonas con distritos)

                        

                        

                            
🔍

                            
Consultas Potentes

                            
SPARQL permite navegar el grafo: zona → distrito → Wikidata en una sola query

                        

                    

                


                

                    

                        

                            🏗️ Clase: GreenZone
                        

                        

                            

                                
URI:

                                gz:GreenZone
                            

                            

                                
Descripción:

                                
Representa una zona verde municipal (parque, jardín, etc.)

                            

                            

                                
Propiedades:

                                
    
                                    
  • • gz:district (string)
    • 
                                    
  • • gz:fileNumber (string)
    • 
                                    
  • • gz:destination (string)
    • 
                                    
  • • gz:plot (string)
    • 
                                    
  • • gz:inDistrict (ObjectProperty)
    • 
                                

                            

                        

                    


                    

                        

                            🏛️ Clase: District
                        

                        

                            

                                
URI:

                                gz:District
                            

                            

                                
Descripción:

                                
Representa un distrito administrativo de Madrid

                            

                            

                                
Enlaces:

                                
• owl:sameAs → Wikidata

                            

                        

                    

                


                

                    
Ejemplo de Triples RDF

                    
@prefix gz: <http://linkeddata.greenzonesmadrid.org/ontology/gz#> .
@prefix owl: <http://www.w3.org/2002/07/owl#> .

# Zona Verde
<http://.../resource/zone/1> a gz:GreenZone ;
    gz:district "CENTRO" ;
    gz:fileNumber "300000" ;
    gz:destination "DOTACIONAL SERVICIOS COLECTIVOS..." ;
    gz:plot "5025.42 m2" ;
    gz:inDistrict <http://.../resource/district/CENTRO> .

# Distrito
<http://.../resource/district/CENTRO> a gz:District ;
    rdfs:label "CENTRO"@es ;
    owl:sameAs <https://www.wikidata.org/entity/Q1763376> .
