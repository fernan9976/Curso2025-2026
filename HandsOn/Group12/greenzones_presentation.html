📋 Resumen del Proyecto

🎯 Objetivo

Transformar el inventario de zonas verdes del Ayuntamiento de Madrid en Linked Open Data

🔗 Enlazado

Conexión con Wikidata para enriquecer los datos con información externa

✅ Cumplimiento de Requisitos

  • ✓ Una sola ontología unificada (madrid-urban-ontology.ttl)
  • ✓ 150 instancias RDF (>100 requerido)
  • ✓ Distritos como entidades (no strings)
  • ✓ Enlaces externos a Wikidata con owl:sameAs
  • ✓ Licencias documentadas (CC BY 4.0)

🏗️ Arquitectura de la Ontología

Clases Principales

🌳 gz:GreenZone

Representa una zona verde municipal (parque, jardín, etc.)

Propiedades: distrito, superficie, destino, ubicación...

🏛️ gz:District

Representa un distrito administrativo de Madrid

Enlaces: Wikidata mediante owl:sameAs

🔗 Relación Clave

gz:inDistrict (ObjectProperty) Dominio: gz:GreenZone Rango: gz:District Ejemplo: zone/1 gz:inDistrict district/CENTRO . district/CENTRO owl:sameAs <wikidata.org/entity/Q1763376> .

🔍 Consulta 1: Contar Zonas Verdes

❓Pregunta: ¿Cuántas zonas verdes hay en total?

Consulta SPARQL:

PREFIX gz: <http://linkeddata.greenzonesmadrid.org/ontology/gz#> SELECT (COUNT(?zone) AS ?numZonas) WHERE { ?zone a gz:GreenZone . }

Resultado:

150 zonas verdes

✅ Se han transformado todas las instancias correctamente

🔍 Consulta 2: Datos de Zonas con Distritos

❓Pregunta: Mostrar zonas con su distrito enlazado

Consulta SPARQL:

SELECT ?zone ?districtName ?fileNumber WHERE { ?zone a gz:GreenZone ; gz:fileNumber ?fileNumber ; gz:inDistrict ?districtRes . ?districtRes rdfs:label ?districtName . } LIMIT 5

Resultados (muestra):

✅ zone/1 → Distrito: CENTRO → File: 300000

✅ zone/2 → Distrito: CENTRO → File: 300001

✅ zone/38 → Distrito: ARGANZUELA → File: 300032

🔍 Consulta 3: Verificar Enlaces a Wikidata

❓Pregunta: ¿Los distritos están enlazados con Wikidata?

Consulta SPARQL:

SELECT ?districtRes ?label ?wikidata WHERE { ?districtRes a gz:District ; rdfs:label ?label ; owl:sameAs ?wikidata . }

Resultados:

🔗 CENTRO → wikidata.org/entity/Q1763376

🔗 ARGANZUELA → wikidata.org/entity/Q2085949

🔗 RETIRO → wikidata.org/entity/Q2085951

🔗 SALAMANCA → wikidata.org/entity/Q2085956

✅ Todos los distritos están correctamente enlazados con Wikidata

🔍 Consulta 4: Zonas por Distrito

❓Pregunta: ¿Cuántas zonas verdes hay en cada distrito?

Consulta SPARQL:

SELECT ?districtRes (COUNT(?zone) AS ?numZonas) WHERE { ?zone a gz:GreenZone ; gz:inDistrict ?districtRes . } GROUP BY ?districtRes

🔍 Consulta 5: Filtrar por Distrito CENTRO

❓Pregunta: ¿Qué zonas pertenecen al distrito Centro?

Consulta SPARQL:

SELECT ?zone ?file ?dest WHERE { ?zone gz:inDistrict <http://.../resource/district/CENTRO> ; gz:fileNumber ?file ; gz:destination ?dest . }
